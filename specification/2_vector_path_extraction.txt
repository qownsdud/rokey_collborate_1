[사양서 2] 이미지 경로 추출 및 로봇 좌표 변환 (AI 결과물 → 로봇 동작 정보)

1. 목적
AI가 생성한 래스터(픽셀) 기반 라인아트 이미지를 로봇팔이 실제로 따라 그릴 수 있는 연속적인 선 경로(Waypoint 목록) 및 로봇 작업 좌표계(X, Y, Z)로 변환한다.

2. 픽셀 방식 대신 벡터(경로) 방식을 사용하는 이유
- 픽셀 단위(도트 찍기 또는 래스터 스캔)로 그리면 펜의 상승/하강(Z축 이동)이 수만 번 발생하여 1장당 소요 시간이 비현실적으로 길어짐
- 잉크 번짐, 종이 찢어짐, 로봇 관절 마모 및 진동 유발
- 따라서 "연속된 선(Stroke)" 단위로 좌표를 추출해야 사람처럼 빠르고 자연스럽게 그릴 수 있음

3. 이미지 → 경로 추출 파이프라인 (OpenCV / Python 기반, 1초 이내 처리)
단계 1) 전처리 및 이진화 (Binarization)
- 입력 이미지를 그레이스케일로 변환 후 Otsu Thresholding 또는 고정 임계값으로 순수 흑(0)/백(255) 이미지로 변환
- 미세한 점/잡티 제거를 위해 모폴로지 연산(Morphology Open/Close) 선택적 적용

단계 2) 세선화 (Skeletonization / Thinning) 또는 외곽선 추출
- 두꺼운 선이 외곽선 2줄(이중선)로 인식되는 것을 방지하기 위해 세선화(`cv2.ximgproc.thinning` 또는 `skimage.morphology.skeletonize`)를 적용하여 1픽셀 두께의 중심선 추출
- 외곽선 기반 스타일을 원할 경우 `cv2.findContours` 활용 가능

단계 3) 경로 단순화 (Polyline Simplification)
- 추출된 픽셀 좌표열을 그대로 로봇에 넘기면 점이 너무 많아 움직임이 끊김
- Douglas-Peucker 알고리즘(`cv2.approxPolyDP`)을 적용해 직선 구간은 시작점/끝점만 남기고 곡선 구간만 적당한 간격으로 유지 (데이터 크기 80~90% 이상 감소)

단계 4) 노이즈 필터링 및 경로 순서 최적화
- 너무 짧은 선분(예: 총 길이 5픽셀 미만 또는 점 2개 이하의 잡선) 제거
- 공중 이동(Pen-Up) 시간을 줄이기 위해 최근접 이웃(Nearest Neighbor) 기반의 경로 정렬(TSP 휴리스틱) 적용: 한 선의 끝점에서 가장 가까운 다음 선의 시작점으로 이동

4. 로봇 작업 좌표 변환 (캘리브레이션)
- 이미지 픽셀 좌표 `(px, py)` (단위: px, 범위: 0~W, 0~H)를 종이 영역의 실제 로봇 기준 좌표 `(X, Y)` (단위: mm 또는 m)로 선형 매핑
  * 예: A4 용지(210mm x 297mm) 중 여백을 제외한 작업 영역(예: 160mm x 160mm)에 맞춰 스케일링 및 오프셋 적용
  * 종이 기울어짐 보정이 필요할 경우 4점 기준(원점, X축 끝점, Y축 끝점) 아핀/호모그래피 변환 적용
- Z축 상태 정의:
  * `Z_draw`: 펜촉이 종이에 닿아 그리는 높이
  * `Z_up`: 선과 선 사이를 이동할 때 펜을 들어 올리는 안전 높이 (예: `Z_draw + 10~20mm`)

5. 출력 데이터 포맷 (동작 프로그램 전달용 JSON / ROS2 메시지 예시)
- 각 선(Stroke)을 좌표 배열로 묶어 전달:
  [
    { "stroke_id": 1, "points": [[x1, y1], [x2, y2], [x3, y3]] },
    { "stroke_id": 2, "points": [[x4, y4], [x5, y5]] }
  ]
- 로봇 제어 프로그램은 각 Stroke의 첫 점으로 `Z_up` 상태에서 이동 → `Z_draw`로 하강 → `points` 순차 추종(직선 보간 MoveL) → 마지막 점에서 `Z_up` 상승 순으로 실행
